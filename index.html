Paso a Paso de Puesta en Marcha

Progreso: 0/4 Completado
1

Instalar Dependencias de Python

Abre tu terminal en la carpeta del proyecto y ejecuta:

pip install -r requirements.txt

💡 En Windows también puedes simplemente hacer doble clic sobre install.bat.

2

Cargar la Extensión en Cisco Packet Tracer

  1. Abre tu software Cisco Packet Tracer.
  2. En el menú superior haz clic en: Extensions ➡️ Scripting ➡️ Configure PT Script Modules...
  3. Haz clic en el botón Add... y selecciona el archivo MCP-Control-Center.pts del proyecto.
  4. Presiona Yes si te pide confirmación.
  5. Se abrirá la ventana MCP Control Center. ¡Déjala abierta o minimízala!
3

Configurar tu Agente de IA

Pasa a la pestaña "2. Agentes IA" para copiar el bloque adaptado a tu editor (Antigravity IDE, Claude Code, Cursor, OpenCode, etc.).

4

¡Diseñar y Orquestar en Vivo!

Dile a tu agente lo que quieres crear y observa cómo se dibuja en tiempo real:

"Crea 2 routers 2911 conectados por serial, con 1 PC a cada router y enrutados por RIPv2 con prueba de ping."

Biblioteca de Laboratorios Listos

                
Copia cualquiera de estos prompts y envíaselo a tu agente para que despliegue la red completa:

            


            

                
                

                    

                        Laboratorio 1 · CCNA Routing
                        
                    

                    

Crea 2 routers Cisco 2911 conectados mediante enlace Serial usando tarjetas HWIC-2T en la ranura 0/0. Conecta una PC a cada router mediante Ethernet directo, asigna el direccionamiento IP correspondiente (192.168.10.0/24 y 192.168.20.0/24), enrútalos mediante RIPv2 y realiza una prueba de ping de extremo a extremo.
                    

                


                
                

                    

                        Laboratorio 2 · Inter-VLAN Routing
                        
                    

                    

Diseña una red con 1 switch Cisco 2960 y 1 router 2911. Crea la VLAN 10 (Ventas) y VLAN 20 (TI). Conecta 2 PCs al switch en sus respectivas VLANs. Configura un enlace troncal 802.1Q hacia el router e implementa Router-on-a-Stick con subinterfaces Gig0/0.10 y Gig0/0.20 para permitir la comunicación entre ambas VLANs.
                    

                


                
                

                    

                        Laboratorio 3 · OSPF Triángulo
                        
                    

                    

Construye una topología de 3 routers Cisco 2911 en triángulo con OSPF en el área 0. Conecta un switch 2960 y una PC en cada extremo. Configura router-id y publica las redes en OSPF. Aplica fast forward para acelerar la convergencia y lee la tabla de rutas de cada router para verificar el estado FULL.
                    

                


                
                

                    

                        Laboratorio 4 · Servidor Web & DNS
                        
                    

                    

Crea 1 switch 2960, conecta 1 PC y 1 Server-PT. Configura el servidor con IP 192.168.1.10, habilita el servicio DNS con el registro www.empresa.local apuntando a su IP, habilita el servidor Web HTTP con una página de bienvenida personalizada y desde la PC abre el navegador web consultando el dominio www.empresa.local.
                    

                

            

        


        
        
        
        

            

                
Preguntas Frecuentes y Diagnóstico

                
Respuestas técnicas sobre el funcionamiento del puente y la extensión.

            


            

                

                    
¿Por qué dice "Waiting for your agent" o "Lost MCP server"?

                    

                        Es totalmente normal. La extensión de Packet Tracer incluye un mecanismo de File bridge de respaldo automático (🟢 verde). Aunque el puerto HTTP 54321 no esté retenido en ese segundo, las órdenes se envían por archivo local y se dibujan sin pérdida ni retraso.
                    

                

                

                    
¿Funciona en cualquier computadora o ruta?

                    

                        Sí. El archivo run_server.py y setup_project.py resuelven las rutas de Python y de los directorios de usuario dinámicamente en tiempo de ejecución, funcionando en Windows, macOS o Linux sin tocar nada a mano.
                    

                

                

                    
¿Cómo verificar que el agente tiene comunicación?

                    

                        Puedes pedirle a tu agente: "Ejecuta pt_master_catalog y dime qué routers tengo disponibles". Si responde con la lista de routers, el canal MCP está 100% operativo.
                    

                

                

                    
¿Se necesitan permisos de Administrador?

                    

                        No. Todo el servidor corre en el espacio de usuario estándar y no modifica archivos del sistema operativo protegidos.
